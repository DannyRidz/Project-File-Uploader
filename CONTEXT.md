# File Storage

A personal storage space where authenticated users organize and retrieve their uploaded files.

## Language

**User**:
A person with an account and a private storage space.
_Avoid_: Member, customer

**Folder**:
A user-owned container used to organize files.
_Avoid_: Directory

**File**:
An uploaded item owned by a user, optionally organized inside a folder.
_Avoid_: Document, attachment

**Root**:
The part of a user's storage containing files that are not assigned to a folder.
_Avoid_: Home folder

**Session**:
A temporary authenticated visit associated with a browser.
_Avoid_: Login
